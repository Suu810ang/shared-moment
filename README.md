# Shared Moment — Prototype

A calm web experience that helps people feel connected through short, real shared moments.

## How to try it

Open the live version or open `index.html` in any browser.

1. Choose how you feel right now
2. Wait while it finds someone
3. Talk, share, or draw together for a few minutes

## What's included

- Mood-based matching simulation
- Conversation prompts with partner replies
- Simple drawing canvas
- 10-minute session timer
- No accounts, no tracking

Made as a starting prototype for building something that helps people feel less alone.
